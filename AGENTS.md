# Working rules

`NormalityContract` is the automatic sealed system baseline; `Expectation` is an explicit user market question. Their immutable basis/snapshot must never be recomputed. Deterministic resolvers are authoritative. Every domain, timeline, history, dashboard, brief, and replay market read uses an injected LIVE or REPLAY clock and requires `availableAt <= clock.asOf`. `observedAt`, `ingestedAt`, and `availableAt` are distinct; historical EOD bars may be backfilled later but become admissible only at legitimate publication time. Trading deadlines use `TradingCalendar`; evidence without trustworthy adjusted prices is unsafe and resolves as `UNRESOLVABLE`/`UNSCOREABLE`. Events and audits are append-oriented. Agents cannot trade, resolve, change sealed evidence, or override replay clocks. Order drafts never bypass the dedicated confirmation endpoint. Frontends display server calculations and must not recreate financial logic. Use observational language only—never unsupported causal claims.
